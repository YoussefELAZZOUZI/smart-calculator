# Smart Calculator

A simple web calculator built with PHP and HTML.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal numbers
- Input validation
- Protection against division by zero
- Operator validation

## Technologies

- PHP
- HTML

## Installation

1. Clone the repository:

```bash
git clone https://github.com/YoussefELAZZOUZI/smart-calculator.git
```

2. Enter the project directory:

```bash
cd smart-calculator
```

3. Start the PHP development server:

```bash
php -S 127.0.0.1:8000
```

4. Open the project in your browser:

```text
http://127.0.0.1:8000
```
